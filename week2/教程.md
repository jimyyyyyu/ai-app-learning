## 第 1 节 列表 list：装东西的抽屉

### 讲解
列表 = 一排有编号的抽屉。编号（下标）**从 0 开始数**。

### 例子

```python
books = ["Python入门", "机器学习", "深度学习"]
books[0]        # 第 1 个 -> "Python入门"
books[-1]       # 最后 1 个 -> "深度学习"
books[0:2]      # 第 1、2 个 -> ["Python入门", "机器学习"]
books.append("RAG实战")   # 加一个到末尾
len(books)      # 4
```

### 练习
打开 `week2/exercises.py`，做第 1–4 题（改 TODO 行 → Ctrl+S → 重跑看 ✅）。

### 应用
你的对话历史 messages 就是列表。第 7 节保存聊天记录时，你要遍历它。

## 第 2 节 字典 dict：贴了标签的抽屉

### 讲解
字典 = 每个抽屉**贴了名字标签**（键），而不是编号。想拿什么，报名字。

### 例子

```python
payload = {"model": "deepseek-chat", "temperature": 0.7}
payload["model"]            # 取值 -> "deepseek-chat"
payload["max_tokens"]       # ❌ 键不存在会报 KeyError
payload.get("max_tokens", 2048)   # ✅ 安全取值：没有就给默认值
payload["stream"] = True    # 加一个键
for k, v in payload.items():      # 遍历
    print(k, v)
```

### 练习
exercises.py 第 5–8 题。

### 应用
你发给模型的请求参数 payload 就是字典；模型返回的 JSON 解析后也是字典。

## 第 3 节 嵌套结构：抽屉里还有抽屉

### 讲解
列表里装字典，字典里再装列表和字典——这就是真实世界的 API 数据。拿取的方法只有一招：**一层一层地剥**。

### 例子
模型返回的结构（注意 `choices` 是列表，所以要用 `[0]` 取第一个）：

```python
resp.json()                               # 最外层：字典
resp.json()["choices"]                    # 第二层：列表
resp.json()["choices"][0]                 # 第三层：字典
resp.json()["choices"][0]["message"]      # 第四层：字典
resp.json()["choices"][0]["message"]["content"]   # 第五层：最终文字
```

你的 messages 也是嵌套：**列表**（对话历史）→ **字典**（每条消息）→ **字符串**（内容）。

### 练习
在纸上画出 messages 的"抽屉树"。然后写一行代码，取出 messages 里**最后一条**消息的 content（提示：`[-1]`）。

### 应用
以后所有 API 返回都要这样剥。看不懂结构时，`print(json.dumps(data, ensure_ascii=False, indent=2))` 打印出来看。

## 第 4 节 函数：给一段代码起名字

### 讲解
函数 = 一个**有名字的机器**：喂原料（参数）→ 干活 → 吐成品（返回值）。好处：写一次，反复用。

```python
def 机器名(原料1, 原料2):
    干活
    return 成品
```

### 例子
你 hello_ai.py 里的 `chat(messages)` 就是函数：

```python
def chat(messages):                    # 原料：对话历史
    payload = {"model": ..., "messages": messages}
    resp = requests.post(URL, json=payload, headers=headers)
    return resp.json()["choices"][0]["message"]["content"]   # 成品：AI 的回复
```

调用：`reply = chat(messages)` —— 原料进去，成品出来。

3. `greet(name, tone="你好")`：返回 `f"{tone}，{name}"`（默认参数）

跑 `python my_functions.py` 自己测试。

### 应用
本周项目会把"保存历史"和"加载历史"写成两个函数。第 10 周 RAG 会写 `search()`、`answer()` 等函数——函数是组织代码的基本单位。

## 第 5 节 异常处理：给程序装安全气囊

### 讲解
程序会遇到意外：断网、key 填错、文件不存在。不处理就**当场崩溃**。`try/except` 就是安全气囊：

```python
try:
    可能出错的代码
except 错误类型:
    出错时的兜底方案
```

### 例子
你 hello_ai.py 里已经有了：

```python
try:
    reply = chat(messages)
except Exception as e:
    print(f"出错了：{e}")
```

### 练习
1. 故意把环境变量里的 key 改错，运行 hello_ai.py——观察"有 try"和"没 try"（临时删掉 try）的区别
2. 在 `my_functions.py` 写一个 `safe_divide(a, b)`：除数为 0 时返回 `"不能除以 0"` 而不是崩溃

### 应用
第 13 周你做 API 服务后，任何一次网络抖动都不该让服务死掉——try/except 是命根子。

## 第 6 节 JSON 读写文件：给记忆存盘

### 讲解
第 1 周你已经会 `json.loads/dumps`（字符串和 Python 对象互转）。本周升级：**直接读写文件**。

```python
import json

# 写：Python 对象 -> 文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(数据, f, ensure_ascii=False, indent=2)

# 读：文件 -> Python 对象
with open("data.json", "r", encoding="utf-8") as f:
    数据 = json.load(f)
```

记住三件套：`"w"` 是写、`"r"` 是读、`encoding="utf-8"` 保证中文不乱码。`with` 语句 = 用完自动关门，标准写法。

### 应用

## 第 7 节 pathlib：文件操作五武器

### 讲解
把"路径"当对象玩，而不是拼字符串。organizer 项目只需要 5 个武器：

| 武器 | 写法 | 作用 |
|---|---|---|
| 拼路径 | `Path("demo_files") / "报告.txt"` | 用 `/` 拼接，自动处理斜杠 |
| 看信息 | `.name` / `.suffix` / `.parent` | 文件名 / 扩展名 / 父文件夹 |
| 遍历 | `for item in Path(...).iterdir()` | 把文件夹里的东西一个个拿出来 |
| 判断 | `.is_file()` / `.is_dir()` / `.exists()` | 是文件？是文件夹？存在吗？ |
| 动手 | `.mkdir(exist_ok=True)`、`shutil.move(a, b)` | 建文件夹、移动文件 |

### 例子

## 第 8 节 项目 A：聊天记录持久化（步骤引导）

### 需求
hello_ai.py 一退出就失忆。让它：**退出时把 messages 存进 `chat_history.json`，下次启动自动加载接着聊**。

### 分步引导（每一步做完都跑一遍验证）

**步骤 1**：在文件顶部加 `import json`

**步骤 2**：写一个保存函数：

```python
def save_history(messages):
    with open("chat_history.json", "w", encoding="utf-8") as f:
        json.dump(messages, f, ensure_ascii=False, indent=2)
```

**步骤 3**：写一个加载函数，文件不存在时返回"全新人设"：

```python
def load_history():
    try:
        with open("chat_history.json", "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return [{"role": "system", "content": "你是一个耐心友好的中文学习助手。"}]
```

**步骤 4**：改造 main()：
- 开头：`messages = load_history()`（替换原来写死的初始 messages）
- 退出前（quit 分支里）：调用 `save_history(messages)`
